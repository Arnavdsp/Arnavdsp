## About

I build AI systems that are grounded, measurable, and operationally reliable.

My work sits at the intersection of:
- LLM agents and workflow orchestration
- Retrieval and RAG systems
- Evaluation, benchmarking, and failure analysis
- Inference optimization and system trade-offs
- Applied ML and real-world AI engineering

I am a B.Tech student at IIT Indore, with a background in Space Science & Engineering, and I focus on building systems that do more than demo well — they survive real constraints.

## Featured projects

### 1) edgar-mcp
A tool-based MCP server that exposes SEC filing data to an AI agent while handling real-world financial-data problems like ambiguous company names, fiscal-year mismatch, stale values, and restatements.

- Built for: SEC data access + agent tool reliability
- Focus: grounded financial reasoning, safe refusals, tool-driven analysis
- Evidence: evaluation harness with measured results and failure analysis
- Link: https://github.com/Arnavdsp/edgar-mcp

### 2) DocuMind
An end-to-end grounded document Q&A system with page-aware extraction, retrieval, reranking, citations, and explicit abstention when evidence is insufficient.

- Built for: grounded document AI
- Focus: retrieval quality, evidence attribution, abstention, production-style RAG design
- Link: https://github.com/Arnavdsp/DocuMind
### 3) DRDO-Internship-Overview
Built and evaluated an end-to-end high-altitude tiny object detection pipeline using state-of-the-art machine learning, deep learning, and transformer-based computer vision techniques.
- Built for: Improving the Detection Capabilities of Modern-Day/Upcoming AI-integrated Drone Systems
- Focus : Real-time object detection, loss optimization, Defence Research
- Link : https://github.com/Arnavdsp/DRDO-Internship-Overview


### 4) Automatron
A multi-agent decision-support system with deterministic validation, workflow design, and human approval gates for high-risk decision tasks.

- Built for: agent orchestration and structured reasoning
- Focus: task decomposition, verification, auditability, workflow reliability
- Link: https://github.com/Arnavdsp/Automatron
  
### 5) Aura - The Mental Wellness Agent
A multimodal mental wellness agent powered by  Gemma 3n, optimized for Mental Wellness through PEFT using LORA and DPO.
- Built for: Multimodal Analysis of the User's Mental Health
- Focus : Analysis, Reasoning, Reliability
- Link: https://github.com/Arnavdsp/Aura-The-Mental-Wellness-Coach

### 6) AI Systems Lab
A research scratchpad for experiments in agent planning, retrieval evaluation, quantization, caching, and benchmarking and logging my learning throughout the Year.

- Built for: AI systems research and iteration
- Focus: understanding trade-offs in real LLM systems
- Link: https://github.com/Arnavdsp/ai-systems-lab

## What I care about

I care more about **reliability, measurement, and trade-offs** than flashy demos.

In practice, that means:
- building tools that fail honestly instead of pretending certainty
- turning retrieval and agent issues into measurable outcomes
- understanding what breaks in real systems and why
- designing workflows where verification matters as much as generation

## Current focus

- LLM agents and workflow orchestration
- Retrieval systems and grounded generation
- Evaluation design and benchmark-driven iteration
- Inference optimization and latency trade-offs
- Building AI systems that are testable, explainable, and usable
